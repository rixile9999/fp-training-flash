title: 保持结构的变换：函子
---
`map` 保持容器的**形状**不变，只改变里面的值。对列表来说，长度和顺序就是形状。具有这个性质的结构叫作函子（Functor），这个性质用两条定律来表述。

```gleam
// 恒等律：用什么也不做的函数 map，结果与原值相同
list.map(xs, fn(x) { x }) == xs

// 组合律：map 两次，等于用组合后的函数 map 一次
list.map(list.map(xs, g), f) == list.map(xs, fn(x) { f(g(x)) })
```

第一条定律意味着 `map` 不会增加、删除或重新排列元素。有了第二条定律，把管道中连续的 `map` 步骤合并成一个或拆开，含义都不会改变。

反过来，`filter` 是改变形状的操作。结果的长度可能与输入不同，所以函子定律不成立。

## 这个概念用在哪里

- 需求中出现“保持长度和顺序”时，就需要保持结构的变换。
- `Option` 和 `Result` 的 `map` 也遵循同样的定律：有值就变换，没有值或是错误就原样保留。
