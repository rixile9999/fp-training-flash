title: 持久化数据结构与路径复制
---
更新之后旧版本仍原样保留、可以继续使用的数据结构，叫作**持久化**（persistent）数据结构。如果更新会让旧版本消失，就是**短暂**（ephemeral）数据结构。

Gleam 的值全都是不可变的，所以用 Gleam 构造的数据结构天然就是持久化的。因此设计时要问的不是“如何获得持久性”，而是“每次更新要新建多少东西”。

## 路径复制

更新只新建**到变化处为止的路径上的节点**，其余部分与旧版本共享。用替换列表第 i 个元素的函数来看就是这样。

```gleam
pub fn set_at(items: List(a), index: Int, value: a) -> List(a) {
  case items, index {
    [], _ -> []
    [_, ..rest], 0 -> [value, ..rest]
    [first, ..rest], _ -> [first, ..set_at(rest, index - 1, value)]
  }
}
```

前面的 `index + 1` 个格子是新建的，被改格子之后的 `rest` 原样共享。所以改第一个元素是 O(1)，改最后一个是 O(n)。原列表丝毫不变。

在树中，路径是从根到被改节点。下图是在二叉搜索树中插入 5 的情形。只有带撇号（'）的节点是新建的，`10` 和 `1` 由两个版本共享。

```text
   旧版本           新版本
      8                 8'
     / \               / \
    3   10            3'  10
   / \               / \
  1   6             1   6'
                       /
                      5
```

新建的节点数等于从根到变化处的路径长度，所以最多大约是树的高度。如果树是平衡的，一次更新在时间和内存上都是 O(log n)；如果树偏向一侧，就是 O(n)。所以持久化数据结构设计的核心是**让高度保持较低的不变式**。

## 不变式让路径保持很短：左偏堆

左偏堆（leftist heap）是一种能快速取出最小值的优先队列。它维护两条不变式。

- **堆序**：父节点的值不大于子节点的值。所以最小值在根上。
- **左偏性**：把每个节点右脊（只沿右子节点一直走到底的路径）的长度叫作**秩**（rank），左子节点的秩不小于右子节点的秩。

由于第二条不变式，右脊是通往空位的最短路径，秩为 r 的堆至少有 2ʳ - 1 个节点。因此，n 个节点的堆的右脊长度不超过 log₂(n + 1)。合并两个堆只需沿着两个堆的右脊往下走，所以是 O(log n)，也只新建这条路径。插入可以表示为与单节点堆合并，取出最小值可以表示为合并根的两个子节点。如果漏掉合并后比较秩、交换两个子节点的步骤，不变式就会被破坏，右脊就会变长。

## 拉链：反复修改同一处时

如果多次修改同一位置附近，每次都要从根复制路径，这个代价会反复出现。**拉链**（zipper）把当前位置（焦点）和“回去的路”（上下文）一起保存，使移动焦点或修改焦点的值都变成 O(1)。整个结构在往上走时重新组装。用列表拉链来看就是这样。焦点之前的元素反向存储，让离得近的排在前面。

```gleam
pub type ListZipper(a) {
  ListZipper(before: List(a), focus: a, after: List(a))
}

pub fn next(zipper: ListZipper(a)) -> Result(ListZipper(a), Nil) {
  case zipper.after {
    [] -> Error(Nil)
    [first, ..rest] ->
      Ok(ListZipper([zipper.focus, ..zipper.before], first, rest))
  }
}

pub fn set_focus(zipper: ListZipper(a), value: a) -> ListZipper(a) {
  ListZipper(..zipper, focus: value)
}
```

树拉链唯一的不同是：上下文里堆叠的是“从哪一侧的子节点下来的，以及当时留在身后的兄弟子树”。

## 持久性带来的好处与注意事项

- **历史与撤销**：只要留着旧版本就行，不需要复制。
- **回溯**：把新版本传给递归调用，调用方的版本依然不变。
- **内存**：两个版本共享大部分结构，额外的内存只有被改动的路径。
- **注意**：如果反复使用旧版本，摊还代价的保证可能会失效。每次操作都有最坏代价保证的结构（如左偏堆 O(log n) 的合并）没有这个问题。

## 这个概念用在哪里

- 优先队列（左偏堆）、树的编辑（拉链）、编辑历史与撤销。
- `Dict` 和 `Set` 也是持久化数据结构。`insert` 返回新版本，旧版本仍可继续使用。
