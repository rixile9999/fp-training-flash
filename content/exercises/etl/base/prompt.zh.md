把一个文字游戏的字母计分表迁移到新格式。

- 旧格式：每个分数对应获得该分数的大写字母列表，`Dict(Int, List(String))`
- 新格式：每个字母对应一个分数，`Dict(String, Int)`，字母为**小写**

请编写 `transform(legacy)`。

- 旧列表中的每个字母在结果中恰好出现一次。
- 没有字母的分数（空列表）不往结果里添加任何东西。
- 可以假设不会出现同一个字母同时属于多个分数的输入。

```gleam
transform(dict.from_list([#(1, ["A", "E"]), #(2, ["D"])]))
// -> dict.from_list([#("a", 1), #("e", 1), #("d", 2)])
```
