단어 게임의 글자 점수표를 새 형식으로 옮깁니다.

- 기존 형식: 점수마다 그 점수를 받는 대문자 글자 목록 `Dict(Int, List(String))`
- 새 형식: 글자마다 점수 하나 `Dict(String, Int)`, 글자는 **소문자**

`transform(legacy)`를 작성하세요.

- 기존 목록의 모든 글자가 결과에 한 번씩 들어간다.
- 글자가 없는 점수(빈 목록)는 결과에 아무것도 더하지 않는다.
- 같은 글자가 여러 점수에 동시에 들어 있는 입력은 없다고 가정한다.

```gleam
transform(dict.from_list([#(1, ["A", "E"]), #(2, ["D"])]))
// -> dict.from_list([#("a", 1), #("e", 1), #("d", 2)])
```
