把新格式的字母块计分表 `Dict(String, Int)`（小写字母块 -> 分数）还原成旧系统能读取的格式。字母块大多是单个字母，但也有像 `"ch"` 这样由两个字母组成的。请编写 `to_legacy(scores)`。

- 结果是 `Dict(Int, List(String))`：每个分数对应获得该分数的字母块列表。
- 字母块转换为**大写**。
- 每个列表按 `string.compare` 升序（字典序）排列。例如：`"C"`、`"CH"`、`"D"`
- 输入中没有出现的分数，不要作为键放进结果。

```gleam
to_legacy(dict.from_list([#("g", 2), #("a", 1), #("d", 2)]))
// -> dict.from_list([#(1, ["A"]), #(2, ["D", "G"])])
```
