迁移仓库系统时需要转换数据格式。旧系统为每个货架保存放在该货架上的商品编码列表。新系统则希望能用商品编码直接找到货架位置。

请编写 `index_by_code(shelves)`。

- 输入：`Dict(String, List(String))`（货架名称 -> 商品编码列表）
- 输出：`Dict(String, String)`（整理后的商品编码 -> 货架名称）
- 编码去掉前后空格并转成大写。货架名称保持原样。
- 整理后结果为空字符串的编码（`""`、`"   "` 等）跳过。
- 可以假设不会出现同一个编码放在多个货架上的输入。

```gleam
index_by_code(dict.from_list([#("A1", [" ab-12", "  "]), #("B2", ["cd-34"])]))
// -> dict.from_list([#("AB-12", "A1"), #("CD-34", "B2")])
```
