창고 시스템을 옮기면서 데이터 형식을 바꿉니다. 예전 시스템은 선반마다 그 선반에 놓인 상품 코드 목록을 저장했습니다. 새 시스템은 상품 코드로 선반 위치를 바로 찾으려 합니다.

`index_by_code(shelves)`를 작성하세요.

- 입력: `Dict(String, List(String))` (선반 이름 -> 상품 코드 목록)
- 출력: `Dict(String, String)` (정리한 상품 코드 -> 선반 이름)
- 코드는 앞뒤 공백을 없애고 대문자로 바꾼다. 선반 이름은 그대로 둔다.
- 정리한 결과가 빈 문자열인 코드(`""`, `"   "` 등)는 건너뛴다.
- 같은 코드가 여러 선반에 있는 입력은 없다고 가정한다.

```gleam
index_by_code(dict.from_list([#("A1", [" ab-12", "  "]), #("B2", ["cd-34"])]))
// -> dict.from_list([#("AB-12", "A1"), #("CD-34", "B2")])
```
