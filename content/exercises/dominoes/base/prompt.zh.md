给定一个多米诺骨牌列表，判断能否把每块骨牌恰好用一次，连成一条首尾相接的环形链。

```gleam
pub fn can_chain(stones: List(#(Int, Int))) -> Bool
```

- 骨牌 `#(a, b)` 的两侧分别是数字 `a` 和 `b`。骨牌可以翻转，按 `#(b, a)` 摆放。
- 相邻的两块骨牌，相接一侧的数字必须相同。
- 第一块骨牌的外侧数字也必须与最后一块骨牌的外侧数字相同（绕成一圈）。
- 可能有多块形状相同的骨牌，每一块都要分别使用一次。
- 没有骨牌时结果为 `True`。

用来生成“每个元素”与“只去掉该元素后的其余元素”配对的 `selections` 已经提供。即使有多块形状相同的骨牌，它也只按位置去掉一块。

```gleam
can_chain([#(2, 1), #(2, 3), #(1, 3)])
// -> True    [1|2] [2|3] [3|1]
can_chain([#(1, 2), #(4, 1), #(2, 3)])
// -> False   [4|1] [1|2] [2|3] 能连起来，但 4 和 3 不同
```
