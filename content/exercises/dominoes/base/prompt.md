도미노 돌 목록을 받아, 모든 돌을 한 번씩 써서 한 바퀴 도는 사슬을 만들 수 있는지 판단하세요.

```gleam
pub fn can_chain(stones: List(#(Int, Int))) -> Bool
```

- 돌 `#(a, b)`는 양쪽에 수 `a`, `b`가 있다. 돌은 뒤집어서 `#(b, a)`로 놓을 수 있다.
- 이웃한 두 돌은 맞닿은 쪽의 수가 같아야 한다.
- 첫 돌의 바깥쪽 수와 마지막 돌의 바깥쪽 수도 같아야 한다(한 바퀴).
- 같은 모양의 돌이 여러 개 있을 수 있고, 각각 따로 한 번씩 써야 한다.
- 돌이 없으면 `True`다.

각 원소와 그 원소 하나만 뺀 나머지의 쌍을 만드는 `selections`는 이미 있습니다. 같은 모양의 돌이 여러 개여도 위치 기준으로 하나씩만 뺍니다.

```gleam
can_chain([#(2, 1), #(2, 3), #(1, 3)])
// -> True    [1|2] [2|3] [3|1]
can_chain([#(1, 2), #(4, 1), #(2, 3)])
// -> False   [4|1] [1|2] [2|3]은 이어지지만 4와 3이 다르다
```
