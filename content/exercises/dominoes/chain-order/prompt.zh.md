用多米诺骨牌列表构建一条首尾相接的环形链，并返回这条链本身。

```gleam
pub fn chain(stones: List(#(Int, Int))) -> Result(List(#(Int, Int)), Nil)
```

- 结果是一个把输入的每块骨牌恰好用一次的列表。如果有多块形状相同的骨牌，每块都分别使用。
- 结果中的每块骨牌按实际摆放的方向写出。如果输入中的 `#(3, 1)` 是翻转摆放的，结果里就写成 `#(1, 3)`。
- 结果中任意两块相邻骨牌，前一块的右侧数字等于后一块的左侧数字；第一块的左侧数字也等于最后一块的右侧数字。
- 如果可以构成多条链，返回其中任意一条即可。没有骨牌时返回 `Ok([])`，无法构成链时返回 `Error(Nil)`。

用来生成“每个元素”与“只去掉该元素后的其余元素”配对的 `selections` 已经提供。

```gleam
chain([#(1, 2), #(3, 1), #(2, 3)])
// -> Ok([#(1, 2), #(2, 3), #(3, 1)])   其他正确的链也算对
chain([#(1, 2), #(4, 1), #(2, 3)])
// -> Error(Nil)
```
