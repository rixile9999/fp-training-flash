请编写 `count_words(input)`，统计英文句子（只使用 ASCII 字符）中每个单词出现的次数。结果是 `Dict(String, Int)`。

- 单词是由英文字母（`a`-`z`、`A`-`Z`）和数字（`0`-`9`）连续组成的片段。只由数字组成的片段也是单词。
- 其他所有字符（空格、换行、制表符、标点符号、单引号等）都是分隔单词的分隔符，不会留在结果中。
- 不区分大小写，结果的键用小写。
- 一个单词都没有时，返回空 dict。

判断单个字符是否为小写英文字母或数字的 `is_word_char` 已经写好了。

```gleam
count_words("Go, go\tSTOP!")
// -> dict.from_list([#("go", 2), #("stop", 1)])
```
