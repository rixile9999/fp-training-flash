这里有一个进制转换函数 `rebase`。它能正确检查进制，但会用 `list.filter` 悄悄丢掉超出范围的数字位，然后继续计算。所以即使二进制输入里混进了 `2`，也会以 `Ok` 结束。

请修改它：不要丢弃错误的数字位，而是用 `Error(InvalidDigit(该数字位))` 报告出来。

- 小于 0 或大于等于 `input_base` 的数字位就是错误的数字位。
- 有多个错误数字位时，报告最前面的那个。
- 其余行为（转换结果、进制检查及其顺序、值为 0 时返回 `[0]`）保持不变。

```gleam
rebase(digits: [1, 2, 1], input_base: 2, output_base: 10)
// 现在：Ok([3])   修改后：Error(InvalidDigit(2))
```
