분석 파이프라인에서 RNA 서열이 원래 DNA보다 짧게 나오는 문제가 발견되었습니다. `to_rna`가 잘못된 글자를 오류로 알리지 않고 조용히 버리기 때문입니다. 코드를 고치세요.

올바른 동작은 다음과 같습니다.

- `G`→`C`, `C`→`G`, `T`→`A`, `A`→`U`로 바꿔 입력 순서대로 이어 붙이고 `Ok`로 감싼다. 빈 문자열은 `Ok("")`이다.
- 네 대문자가 아닌 글자가 하나라도 있으면 `Error(Nil)`을 반환한다.

```gleam
to_rna("ACGT")  // -> Ok("UGCA")
to_rna("ACXT")  // -> Error(Nil)   (지금은 Ok("UGA")가 나온다)
```
