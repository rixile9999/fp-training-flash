아래 모듈은 이진 탐색 트리(작거나 같으면 왼쪽, 크면 오른쪽)로 정수를 정렬합니다. 그런데 `sorted_data([2, 1, 3])`가 `[1, 2, 3]`이 아니라 `[2, 1, 3]`을 돌려준다는 신고가 들어왔습니다. 고치세요.

- `sorted_data(data)`는 `data`의 값을 오름차순으로, 같은 값은 개수만큼 모두 담아 돌려준다.
- `to_tree`는 다른 곳에서도 쓰이므로 트리 모양이 바뀌면 안 된다.

```gleam
sorted_data([2, 1, 3, 6, 7, 5])
// 지금:   [2, 1, 3, 6, 5, 7]
// 기대값: [1, 2, 3, 5, 6, 7]
```
