트리는 `Empty` 또는 `Node(data, left, right)` 두 모양뿐이라서, 트리를 다루는 함수도 이 두 경우를 `case`로 나누고 서브트리에만 재귀하면 됩니다(`algebraic-data-types`, `structural-recursion-induction`).

`insert`는 빈 자리에 도착하면 새 노드를 만들고, 노드를 만나면 값을 비교해 **한쪽 서브트리에만** 넣은 새 노드를 돌려줍니다. 반대쪽 서브트리는 복사하지 않고 그대로 공유합니다. 불변 트리에 값을 넣어도 내려간 경로의 노드만 새로 생기므로 비용이 트리 높이에 비례합니다(`immutability-structural-sharing`). 규칙이 "작거나 같으면 왼쪽"이므로 가드는 `value <= data`입니다.

`to_tree`는 목록을 앞에서부터 접으며(`list.fold`) 하나씩 넣습니다. 넣는 순서가 트리 모양을 결정하므로, `list.fold_right`로 뒤에서부터 넣으면 루트부터 달라집니다.

`sorted_data`는 중위 순회(왼쪽, 자신, 오른쪽)입니다. 왼쪽 서브트리의 값은 모두 자기보다 작거나 같고 오른쪽은 모두 크므로 이 순서가 곧 오름차순입니다. 해답은 오른쪽부터 펼쳐 누적자 앞에 붙이는 방식이라 이어 붙이기가 필요 없습니다. `list.flatten([왼쪽, [data], 오른쪽])`처럼 써도 결과는 같지만, 왼쪽으로 치우친 트리에서는 이어 붙이기 복사가 쌓입니다.

흔한 실수는 같은 값을 오른쪽에 넣거나(`<`만 사용), 이미 있는 값이면 넣지 않아서 중복을 잃는 것입니다.
