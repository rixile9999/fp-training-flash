도서관 무인 반납기가 바코드를 잘못 읽어 ISBN에 영문자가 섞이면 반납기 전체가 멈춥니다. ISBN 검사 함수 `is_valid(isbn: String) -> Bool`이 잘못된 글자에서 `let assert`로 멈추기 때문입니다. 어떤 입력에도 멈추지 않고 `True` 또는 `False`를 돌려주도록 고치세요.

검사 규칙은 그대로입니다.

- 하이픈(`-`)을 지운 뒤 글자가 정확히 10개여야 한다.
- 앞 9글자는 숫자, 마지막 글자는 숫자 또는 대문자 `X`(값 10)여야 한다. `X`는 마지막 자리에만 올 수 있다.
- `d₁×10 + d₂×9 + … + d₁₀×1`이 11로 나누어떨어져야 한다.
- 위 규칙을 하나라도 어기면 `False`다. 잘못된 글자를 다른 값으로 바꿔 계산하지 않는다.

```gleam
is_valid("3-598-21507-X")  // -> True
is_valid("3-598-2A508-8")  // -> False   (지금은 프로그램이 멈춘다)
```
