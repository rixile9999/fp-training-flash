图书馆的自助还书机误读条码，ISBN 中混入英文字母时，整台还书机都会停止工作。原因是 ISBN 检查函数 `is_valid(isbn: String) -> Bool` 遇到错误字符时会因 `let assert` 而崩溃。请修改它，使它对任何输入都不崩溃，并返回 `True` 或 `False`。

检查规则不变。

- 去掉连字符（`-`）后必须正好有 10 个字符。
- 前 9 个字符必须是数字，最后一个字符必须是数字或大写 `X`（值为 10）。`X` 只能出现在最后一位。
- `d₁×10 + d₂×9 + … + d₁₀×1` 必须能被 11 整除。
- 违反任何一条规则就是 `False`。不要把错误字符换成别的值来计算。

```gleam
is_valid("3-598-21507-X")  // -> True
is_valid("3-598-2A508-8")  // -> False   （现在程序会崩溃）
```
