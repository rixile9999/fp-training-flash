实现 `is_valid(isbn: String) -> Bool`，检查录入图书管理系统的 ISBN-10 是否正确。无论传入什么字符串，都不能崩溃，必须返回 `True` 或 `False`。

规则如下。

1. 连字符（`-`）无论在哪里、有几个，都先去掉再看。
2. 去掉后必须正好有 10 个字符。
3. 前 9 个字符必须是数字（`0`–`9`）。最后一个字符是数字或大写 `X`，`X` 表示 10。`X` 只能出现在最后一位。
4. 设各字符的值为 d₁ … d₁₀，必须满足下式。

```text
(d₁ × 10 + d₂ × 9 + d₃ × 8 + … + d₉ × 2 + d₁₀ × 1) mod 11 == 0
```

例如 `3-598-21508-8` 得到 `3×10 + 5×9 + 9×8 + 8×7 + 2×6 + 1×5 + 5×4 + 0×3 + 8×2 + 8×1 = 264`，264 能被 11 整除，所以是正确的。

```gleam
is_valid("3-598-21508-8")  // -> True
is_valid("3-598-21507-X")  // -> True
is_valid("3-598-21508-9")  // -> False
```
