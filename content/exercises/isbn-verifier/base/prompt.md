도서 관리 시스템에 입력된 ISBN-10이 올바른지 확인하는 `is_valid(isbn: String) -> Bool`을 구현하세요. 어떤 문자열이 들어와도 멈추지 말고 `True` 또는 `False`를 반환해야 합니다.

규칙은 다음과 같습니다.

1. 하이픈(`-`)은 어디에 몇 개가 있든 지우고 본다.
2. 지운 뒤 글자가 정확히 10개여야 한다.
3. 앞 9글자는 숫자(`0`–`9`)여야 한다. 마지막 글자는 숫자 또는 대문자 `X`이고, `X`는 10을 뜻한다. `X`는 마지막 자리에만 올 수 있다.
4. 글자 값을 d₁ … d₁₀이라 할 때 다음 식이 성립해야 한다.

```text
(d₁ × 10 + d₂ × 9 + d₃ × 8 + … + d₉ × 2 + d₁₀ × 1) mod 11 == 0
```

예를 들어 `3-598-21508-8`은 `3×10 + 5×9 + 9×8 + 8×7 + 2×6 + 1×5 + 5×4 + 0×3 + 8×2 + 8×1 = 264`이고 264는 11로 나누어떨어지므로 올바릅니다.

```gleam
is_valid("3-598-21508-8")  // -> True
is_valid("3-598-21507-X")  // -> True
is_valid("3-598-21508-9")  // -> False
```
