为了分析故障，请接收日志行列表，返回一个把消息按级别收集成列表的字典。

- 如果一行以 `[` 开头，且后面有 `]`，那么开头的 `[` 与**第一个** `]` 之间的文字就是级别。级别要转换成大写。
- 第一个 `]` 之后的全部文字**只去掉开头的空白**，就是消息。消息中即使有 `[` 或 `]` 也原样保留。
- 排除不以 `[` 开头或没有 `]` 的行。
- 每个级别的消息列表保持在日志中出现的顺序。结果中只包含至少出现过一次的级别。

```gleam
messages_by_level([
  "[ERROR] 磁盘不足",
  "[info] 请求重启",
  "[ERROR]   重试失败 [3 次]",
])
// -> dict.from_list([
//   #("ERROR", ["磁盘不足", "重试失败 [3 次]"]),
//   #("INFO", ["请求重启"]),
// ])
```
