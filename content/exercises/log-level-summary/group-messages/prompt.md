장애 분석을 위해 로그 줄 목록을 받아, 레벨별 메시지 목록으로 모은 딕셔너리를 반환하세요.

- 줄이 `[`로 시작하고 그 뒤에 `]`가 있으면, 맨 앞 `[`와 **첫 번째** `]` 사이의 글자가 레벨이다. 레벨은 대문자로 바꾼다.
- 첫 번째 `]` 뒤의 글자 전체에서 **앞쪽 공백만** 뗀 것이 메시지다. 메시지 안에 `[`나 `]`가 있어도 그대로 둔다.
- `[`로 시작하지 않거나 `]`가 없는 줄은 제외한다.
- 각 레벨의 메시지 목록은 로그에 나온 순서를 유지한다. 결과에는 한 번 이상 나온 레벨만 들어간다.

```gleam
messages_by_level([
  "[ERROR] 디스크 부족",
  "[info] 재시작 요청",
  "[ERROR]   재시도 실패 [3회]",
])
// -> dict.from_list([
//   #("ERROR", ["디스크 부족", "재시도 실패 [3회]"]),
//   #("INFO", ["재시작 요청"]),
// ])
```
