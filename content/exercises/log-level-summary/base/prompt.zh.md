接收服务器日志行的列表，统计每个日志级别各有多少行，并以字典形式返回。

- 如果一行以 `[` 开头，且后面有 `]`，那么开头的 `[` 与**第一个** `]` 之间的文字就是级别。`]` 后面是消息，内容不限（也可以没有空格）。
- 级别转换成大写后再计数。`[warn]` 和 `[WARN]` 是同一个级别。
- 不以 `[` 开头或没有 `]` 的行不计数。
- 结果中只包含至少出现过一次的级别。

```gleam
count_levels([
  "[INFO] 服务器启动",
  "[warn] 响应延迟 1200ms",
  "缓存初始化",
  "[INFO] 处理请求",
])
// -> dict.from_list([#("INFO", 2), #("WARN", 1)])
```
