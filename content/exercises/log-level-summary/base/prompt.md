서버 로그 줄 목록을 받아, 로그 레벨별로 줄이 몇 개인지 세어 딕셔너리로 반환하세요.

- 줄이 `[`로 시작하고 그 뒤에 `]`가 있으면, 맨 앞 `[`와 **첫 번째** `]` 사이의 글자가 레벨이다. `]` 뒤는 메시지이며 무엇이 와도 된다(공백이 없어도 된다).
- 레벨은 대문자로 바꿔서 센다. `[warn]`과 `[WARN]`은 같은 레벨이다.
- `[`로 시작하지 않거나 `]`가 없는 줄은 세지 않는다.
- 결과에는 한 번 이상 나온 레벨만 들어간다.

```gleam
count_levels([
  "[INFO] 서버 시작",
  "[warn] 응답 지연 1200ms",
  "캐시 초기화",
  "[INFO] 요청 처리",
])
// -> dict.from_list([#("INFO", 2), #("WARN", 1)])
```
