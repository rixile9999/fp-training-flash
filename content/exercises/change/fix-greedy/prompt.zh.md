自助收银机用 `min_coins` 计算找零要给多少枚硬币。现在的代码先选不超过剩余金额的最大硬币，结果在面额为 `[1, 4, 15, 20, 50]` 的海外门店找零 23 时，算出了 4 枚（20 + 1 + 1 + 1）。其实 4 + 4 + 15，3 枚就够了。请修复它，让它始终返回最少的枚数。

- 每种面额的硬币可以使用任意多枚。`coins` 是互不相同的正整数。
- 把最少的硬币枚数放进 `Ok` 返回。`target` 为 0 时结果是 `Ok(0)`。
- 任何组合都凑不出，或 `target` 为负数时，结果是 `Error(ImpossibleTarget)`。
- 即使金额是 9999，也必须在时间限制内完成。

```gleam
min_coins([1, 4, 15, 20, 50], 23)
// 现在：  Ok(4)
// 期望值：Ok(3)
```
