`pop` 移除 `front` 的第一个元素；如果 `front` 为空，就把 `back` 反转一次移到 `front` 再试。每个元素只会被反转移动一次，所以 `pop` 是摊还 O(1)（`amortized-analysis`）。

`take` 可以定义为“取出一个，再从剩余部分取出 n - 1 个”。停下的条件有两个：没有要再取的数量时（`n > 0` 不成立时），以及队列为空时。往累加器 `taken` 前面添加来收集，得到的是取出顺序的逆序，所以停下时用 `list.reverse` 反转一次，恢复到达顺序。累加器加上最后的反转，是尾递归的典型形状（`accumulators-and-tail-recursion`）。

常见错误有三种。不反转累加器，这一批就是逆序的。把停止条件写成 `n >= 0`，会多取一个。像 `case n { 0 -> ... }` 这样只在 0 时停下，n 为负数时会把队列取空。用 `n > 0` 检查，就能一次处理 0 和负数。

`take` 同时返回剩余的队列，是因为队列是不可变的。原来的队列保持不变，所以取出之后的状态只能通过返回值传递。
