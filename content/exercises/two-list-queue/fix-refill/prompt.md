아래 `fifo` 모듈은 리스트 두 개로 만든 선입선출(FIFO) 큐입니다. `front`는 꺼낼 순서대로, `back`은 넣은 순서의 역순으로 원소를 담습니다. 그런데 몇 개를 넣고 꺼내 보면 나중에 넣은 원소가 먼저 나온다는 신고가 들어왔습니다. 고치세요.

- `pop(queue)`는 가장 먼저 넣은 원소와 나머지 큐를 `Ok(#(item, rest))`로 돌려준다. 빈 큐면 `Error(Nil)`이다.
- `to_list(queue)`는 꺼낼 순서대로 나열한다.
- 원소 n개를 넣고 모두 꺼내는 전체 비용은 O(n)이어야 한다. 채점에서 16,000개까지 비용을 잰다.

```gleam
let q = fifo.new() |> fifo.push(1) |> fifo.push(2) |> fifo.push(3)
fifo.pop(q)
// 지금:   Ok(#(3, ...))
// 기대값: Ok(#(1, ...))
```
