这道题同时做两件事：为每个字母累加计数，遇到错误字母时当场停止。“边累加边检查，失败就停止”正是 `list.try_fold` 的形状。函数返回 `Ok(新累加值)` 时继续处理下一个字母；返回 `Error` 时不再看剩下的部分，这个 `Error` 就是整个结果。

关键是把初始值设为 `A`、`C`、`G`、`T` 都为 0 的字典。这样一来，

- 一次都没出现的碱基会以 0 留在结果中；
- `dict.get(counts, letter)` 失败这件事本身就意味着“这不是有效字母”。

不需要另外维护一份有效字母列表，初始字典就在同一处表达了规则。

常见错误有两种。用 `list.fold` 计数并直接跳过不认识的字母，那么连 `"AGXXACT"` 也会得到 `Ok`。反过来，从 `dict.new()` 开始用 `dict.upsert` 计数，那么对于 `""` 或 `"G"` 这类缺少某些碱基的输入，数量为 0 的键就会缺失。

折叠（fold）是把列表归约为一个值的最通用的方法（理论笔记“fold 的普适性：列表递归的共同骨架”）；把失败作为 `Result` 值返回，调用方就无法忽视错误（理论笔记“错误也是值”）。
