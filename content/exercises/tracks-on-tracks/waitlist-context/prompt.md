식당의 대기 명단을 손님 이름 목록 `List(String)`으로 관리합니다. 목록의 맨 앞이 가장 먼저 입장할 손님입니다. 다음 네 함수를 작성하세요.

1. `add_vip(queue, name)`: VIP 손님을 명단 **맨 앞**에 넣는다.
2. `add_guest(queue, name)`: 일반 손님을 명단 **맨 뒤**에 넣는다.
3. `seat_next(queue)`: 맨 앞 손님을 입장시키고 남은 명단을 반환한다. 명단이 비어 있으면 빈 목록을 반환한다.
4. `next_two(queue)`: 다음에 입장할 앞의 두 명을 순서대로 반환한다. 두 명보다 적으면 있는 손님만 반환한다.

```gleam
add_guest(["민지", "도윤"], "하준")
// -> ["민지", "도윤", "하준"]
next_two(["민지"])
// -> ["민지"]
```
