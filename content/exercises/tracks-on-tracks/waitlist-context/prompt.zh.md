餐厅用客人姓名列表 `List(String)` 管理候位名单。列表最前面是最先入座的客人。请编写下面四个函数。

1. `add_vip(queue, name)`：把 VIP 客人放到名单**最前面**。
2. `add_guest(queue, name)`：把普通客人放到名单**最后面**。
3. `seat_next(queue)`：让最前面的客人入座，返回剩下的名单。名单为空时返回空列表。
4. `next_two(queue)`：按顺序返回接下来要入座的前两位。不足两位时，只返回现有的客人。

```gleam
add_guest(["敏智", "道允"], "夏俊")
// -> ["敏智", "道允", "夏俊"]
next_two(["敏智"])
// -> ["敏智"]
```
