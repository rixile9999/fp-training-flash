병합 정렬의 핵심 단계인 "합치기"를 구현하세요. 오름차순으로 정렬된 정수 목록 두 개를 받아, 두 목록의 모든 원소를 담은 오름차순 목록 하나를 반환합니다.

- 입력 `left`, `right`는 각각 오름차순(같은 값이 여러 번 나올 수 있음)이다.
- 결과에는 두 목록의 원소가 **모두**, 같은 값이면 개수만큼 들어간다.
- 한쪽이 비어 있거나 먼저 끝나면 다른 쪽의 남은 원소를 그대로 이어 붙인다.
- `list.sort`는 쓰지 않는다. 두 목록을 이어 붙인 뒤 정렬하지 말고, 머리 원소끼리 비교하며 합친다.

```gleam
merge([1, 4, 9], [2, 3, 10])
// -> [1, 2, 3, 4, 9, 10]
```
