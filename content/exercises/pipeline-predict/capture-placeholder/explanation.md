정답은 `[8, 7, 6]`입니다.

함수 캡처 `f(a, _)`는 `fn(x) { f(a, x) }`의 줄임말입니다. `_`가 있는 자리에 원소가 들어갑니다.

```gleam
[1, 2, 3]
|> list.map(int.subtract(10, _))  // fn(x) { 10 - x } -> [9, 8, 7]
|> list.map(int.subtract(_, 1))   // fn(x) { x - 1 }  -> [8, 7, 6]
```

같은 `int.subtract`라도 `_`의 위치에 따라 "10에서 빼기"와 "1 빼기"로 뜻이 달라집니다. 흔한 실수는 두 캡처를 모두 `x - 10`, `x - 1`로 읽어 `[-10, -9, -8]`이라고 답하는 것입니다. 파이프(`x |> f(a)`)는 값을 항상 첫 인자로 넣지만, 캡처는 원하는 자리를 직접 고를 수 있습니다. 작은 함수를 조합해 파이프라인을 만들 때 인자 순서를 맞추는 도구가 바로 캡처입니다(이론 주제 "함수 합성과 파이프라인").
