答案是 `[8, 7, 6]`。

函数捕获 `f(a, _)` 是 `fn(x) { f(a, x) }` 的简写。元素会放到 `_` 所在的位置。

```gleam
[1, 2, 3]
|> list.map(int.subtract(10, _))  // fn(x) { 10 - x } -> [9, 8, 7]
|> list.map(int.subtract(_, 1))   // fn(x) { x - 1 }  -> [8, 7, 6]
```

同样是 `int.subtract`，随着 `_` 位置的不同，含义也分别变成“从 10 中减去”和“减去 1”。常见错误是把两个捕获都读成 `x - 10`、`x - 1`，答出 `[-10, -9, -8]`。管道（`x |> f(a)`）总是把值放进第一个参数，而捕获可以直接选择想要的位置。用小函数组合出管道时，捕获正是用来对齐参数顺序的工具（理论主题“函数组合与管道”）。
