答案是 `14`。

Gleam 的管道 `a |> f(b)` 会变成 `f(a, b)`。左边的值会放进右边函数的**第一个参数**。所以上面的代码等同于：

```gleam
int.multiply(int.subtract(10, 3), 2)
// int.subtract(10, 3) = 10 - 3 = 7
// int.multiply(7, 2)  = 14
```

常见错误是以为管道的值会放进最后一个参数，算成 `int.subtract(3, 10) = -7`（答案 -14）。这种误解来自其他语言中管道或柯里化的习惯。Gleam 标准库的函数大多把“主要处理的值”放在第一个参数，所以能像 `list |> list.map(f)` 这样自然地串起来。想放到第一个参数以外的位置时，可以像 `int.subtract(100, _)` 这样用 `_` 标出位置（理论主题“函数组合与管道”）。
