答案是 `90`。把每一步的中间值写下来，就是下面这样：

```gleam
[1, 2, 3, 4, 5]
|> list.filter(fn(x) { x % 2 == 1 })   // [1, 3, 5]
|> list.map(fn(x) { x * 10 })          // [10, 30, 50]
|> list.fold(0, fn(acc, x) { acc + x }) // 0 + 10 + 30 + 50 = 90
```

管道的每一步都是只接收上一步结果并返回新值的纯函数。所以不必把整个过程一次性装进脑子里，只要一步一步写下“输入 → 输出”即可（理论主题“函数组合与管道”）。之所以能这样阅读，是因为把任何一步替换成它的结果值，含义都不变（理论主题“引用透明性”）。

常见错误是把 `filter` 的条件读反，保留了偶数（`[2, 4]`），这时答案会变成 60。`x % 2 == 1` 的意思是“保留奇数”。
