정답은 `90`입니다. 단계마다 중간 값을 적으면 다음과 같습니다.

```gleam
[1, 2, 3, 4, 5]
|> list.filter(fn(x) { x % 2 == 1 })   // [1, 3, 5]
|> list.map(fn(x) { x * 10 })          // [10, 30, 50]
|> list.fold(0, fn(acc, x) { acc + x }) // 0 + 10 + 30 + 50 = 90
```

파이프라인의 각 단계는 앞 단계의 결과만 받아 새 값을 돌려주는 순수 함수입니다. 그래서 전체를 한꺼번에 머릿속에 담을 필요 없이, 한 단계씩 "입력 → 출력"을 적어 가면 됩니다(이론 주제 "함수 합성과 파이프라인"). 어떤 단계든 그 결과 값으로 바꿔 써도 의미가 같다는 점이 이런 읽기를 가능하게 합니다(이론 주제 "참조 투명성").

흔한 실수는 `filter`의 조건을 거꾸로 읽어 짝수(`[2, 4]`)를 남기는 것입니다. 이 경우 답이 60이 됩니다. `x % 2 == 1`은 "홀수를 남긴다"입니다.
