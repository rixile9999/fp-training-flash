不使用 `gleam/list`，实现两个合并列表的函数。

- `append(first:, second:)`：返回把 `second` 的元素按顺序接在 `first` 的元素后面的列表。
- `concat(lists)`：接收一个列表的列表，返回把内层列表按顺序拼接而成的一个列表。只展平一层（元素是列表时，那个列表原样保留为元素）。
- 即使有 10 万个小列表，也必须在时间限制内完成。开销必须与**元素总数**成正比。

```gleam
append(first: [1, 2], second: [2, 3, 4, 5])  // -> [1, 2, 2, 3, 4, 5]
concat([[1, 2], [3], [], [4, 5, 6]])          // -> [1, 2, 3, 4, 5, 6]
concat([[[1], [2]], [[3]]])                   // -> [[1], [2], [3]]
```
