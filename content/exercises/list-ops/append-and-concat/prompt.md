`gleam/list`를 쓰지 않고 목록을 합치는 함수 두 개를 구현하세요.

- `append(first:, second:)`: `first`의 원소 뒤에 `second`의 원소를 순서대로 붙인 목록을 반환한다.
- `concat(lists)`: 목록의 목록을 받아, 안쪽 목록들을 순서대로 이어 붙인 목록 하나를 반환한다. 한 단계만 합친다(원소가 목록이면 그 목록은 그대로 원소로 남는다).
- 작은 목록이 10만 개여도 시간 제한 안에 끝나야 한다. 비용이 **전체 원소 수**에 비례해야 한다.

```gleam
append(first: [1, 2], second: [2, 3, 4, 5])  // -> [1, 2, 2, 3, 4, 5]
concat([[1, 2], [3], [], [4, 5, 6]])          // -> [1, 2, 3, 4, 5, 6]
concat([[[1], [2]], [[3]]])                   // -> [[1], [2], [3]]
```
