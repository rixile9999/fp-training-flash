로그 뷰어는 최신 로그를 맨 위에 보여 주려고 아래 모듈의 `reverse`로 로그 줄 목록을 뒤집습니다. 결과는 맞는데, 로그가 20만 줄을 넘으면 화면이 멈춘다는 신고가 들어왔습니다. `reverse`를 목록 길이에 비례하는 시간에 끝나도록 고치세요.

- `reverse(list)`는 지금처럼 원소 순서를 뒤집은 새 목록을 반환한다.
- `gleam/list`는 쓰지 않는다. 모듈 안의 `append`와 `foldl`은 다른 곳에서도 쓰이므로 동작이 바뀌면 안 된다.

```gleam
reverse(["09:00 시작", "09:01 주문 접수", "09:02 결제 완료"])
// -> ["09:02 결제 완료", "09:01 주문 접수", "09:00 시작"]
// 지금: 결과는 같지만 20만 줄에서 시간 제한을 넘는다.
```
