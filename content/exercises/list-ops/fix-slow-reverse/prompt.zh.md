为了把最新的日志显示在最上面，日志查看器用下面模块里的 `reverse` 反转日志行列表。结果是对的，但有人反馈日志超过 20 万行时画面会卡住。请修复 `reverse`，让它在与列表长度成正比的时间内完成。

- `reverse(list)` 和现在一样，返回元素顺序反转后的新列表。
- 不使用 `gleam/list`。模块里的 `append` 和 `foldl` 在其他地方也会用到，所以行为不能改变。

```gleam
reverse(["09:00 启动", "09:01 收到订单", "09:02 支付完成"])
// -> ["09:02 支付完成", "09:01 收到订单", "09:00 启动"]
// 现在：结果相同，但在 20 万行时超出时间限制。
```
