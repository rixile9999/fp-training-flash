商品登记页面会计算新商品名与已有商品名的编辑距离，以提示重复登记。下面的 `distance` 对短名称能给出正确答案，但比较较长的商品描述时就停不下来。请修改它，使它给出与现在相同的答案，并在时间限制内完成。

- 编辑是插入、删除、替换一个字符，每种各算 1 次。字符按 grapheme 计数。
- 即使是两个 250 个字符的名称，也必须在时间限制内完成。

```gleam
distance(from: "usb-c cable 1m", to: "usb-c cable 2m")  // -> 1（现在也正确）
distance(from: <250 个字符>, to: <250 个字符>)          // 现在：算不完
```
