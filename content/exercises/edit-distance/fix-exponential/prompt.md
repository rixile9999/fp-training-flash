상품 등록 화면은 새 상품명과 기존 상품명의 편집 거리를 계산해 중복 등록을 경고합니다. 아래 `distance`는 짧은 이름에서는 맞는 답을 내지만, 긴 상품 설명을 비교하면 끝나지 않습니다. 지금과 같은 답을 내면서 시간 제한 안에 끝나도록 고치세요.

- 편집은 글자 하나 삽입, 삭제, 바꾸기이고 각각 1회로 센다. 글자는 grapheme 단위다.
- 250글자 이름끼리도 시간 제한 안에 끝나야 한다.

```gleam
distance(from: "usb-c cable 1m", to: "usb-c cable 2m")  // -> 1 (지금도 맞음)
distance(from: <250글자>, to: <250글자>)                // 지금: 끝나지 않음
```
