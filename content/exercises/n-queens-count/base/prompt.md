n x n 체스판에 퀸 n개를 서로 공격하지 않게 놓는 방법의 수를 세세요. 퀸은 같은 행, 같은 열, 같은 대각선에 있는 퀸을 공격합니다.

퀸은 위쪽 행부터 한 행에 하나씩 놓습니다. 지금까지 놓은 퀸은 열 번호(0부터) 목록으로 나타내며, **바로 윗 행의 퀸이 맨 앞**에 옵니다. 다음 두 함수를 구현하세요.

- `is_safe(placed: List(Int), col: Int) -> Bool`: 다음 행의 `col` 열에 퀸을 놓아도 `placed`의 어떤 퀸과도 같은 열이나 대각선에 있지 않으면 `True`.
- `count_solutions(n: Int) -> Int`: n x n 판의 배치 수. `n`은 1 이상이다.

퀸을 하나 놓을 때마다 안전한지 확인해서, 안전하지 않은 칸에서는 더 내려가지 마세요. 채점에서 n = 9까지의 탐색 비용을 잽니다.

```gleam
is_safe([1], 2)     // -> False  바로 윗 행의 1열 퀸과 대각선
is_safe([3, 0], 1)  // -> True
count_solutions(4)  // -> 2      [1, 3, 0, 2]와 [2, 0, 3, 1]
```
