统计在 n x n 棋盘上放置 n 个互不攻击的皇后的方法数。皇后会攻击位于同一行、同一列或同一对角线上的皇后。

皇后从最上面一行开始，每行放一个。已放置的皇后用列号（从 0 开始）列表表示，**紧邻上一行的皇后排在最前面**。请实现下面两个函数。

- `is_safe(placed: List(Int), col: Int) -> Bool`：在下一行的第 `col` 列放皇后时，如果与 `placed` 中任何皇后都不在同一列或同一对角线上，则为 `True`。
- `count_solutions(n: Int) -> Int`：n x n 棋盘的摆法数。`n` 至少为 1。

每放一个皇后就检查是否安全，在不安全的格子上不要再往下搜索。评测会测量 n = 9 以内的搜索开销。

```gleam
is_safe([1], 2)     // -> False  与紧邻上一行第 1 列的皇后在同一对角线上
is_safe([3, 0], 1)  // -> True
count_solutions(4)  // -> 2      [1, 3, 0, 2] 和 [2, 0, 3, 1]
```
