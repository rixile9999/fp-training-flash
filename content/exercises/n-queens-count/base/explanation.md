각 행에는 퀸이 정확히 하나 있어야 하므로, 배치는 "행마다 열 하나 고르기"입니다. 위쪽 행부터 한 행씩 열을 고르며 내려가다가, 새 퀸이 이미 놓인 퀸과 공격하면 그 가지를 바로 버립니다. 이것이 백트래킹입니다(`search-space-backtracking`). 모든 행을 채우면 배치 하나를 찾은 것이므로 1을 돌려주고, 각 행에서는 안전한 열마다 아래 행을 센 결과를 더합니다.

`is_safe`는 위쪽 퀸들을 바로 윗 행부터 차례로 보며 행 거리를 1, 2, 3, ...으로 늘립니다. 행 거리가 d인 퀸과 열 차이의 절댓값이 d이면 대각선입니다. 절댓값을 쓰지 않고 `c - col == d`만 확인하면 한쪽 대각선만 막습니다. 바로 윗 행 퀸의 대각선만 확인하는 것도 흔한 실수입니다. 작은 판에서는 우연히 맞다가 8x8에서 틀린 답이 나옵니다.

`placed`를 바로 윗 행이 맨 앞인 리스트로 두면 새 퀸을 놓을 때 앞에 붙이기만 하면 되고(O(1)), 거리 계산도 앞에서부터 1씩 늘리면 됩니다. 불변 리스트라 한 가지를 탐색하고 돌아와도 원래 `placed`가 그대로 남아 있어, 되돌리는 코드가 따로 필요 없습니다.

모든 순열(n!개)을 만든 뒤 조건에 맞는 것을 세는 방법도 답은 같지만, 첫 두 행에서 이미 공격하는 배치까지 끝까지 만듭니다. n = 9에서 가지치기하는 풀이보다 수십 배 많은 일을 합니다.
