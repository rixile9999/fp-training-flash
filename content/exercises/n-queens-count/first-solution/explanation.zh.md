如果每一行都从第 0 列开始依次尝试，并在所有行填满的那一刻停止搜索，那么最先找到的摆法就是字典序最小的。因为第一行列号较小的摆法会被先全部检查，而在其中又是从第二行列号较小的开始检查。

“找第一个解”很自然地可以表达为返回 `Result` 的递归。下面各行的搜索结果是 `Ok` 时，原样向上传递；是 `Error(Nil)` 时，转到这一行的下一列。所有列都失败时，这一行也返回 `Error(Nil)`，让上一行去尝试下一列。这就是回溯（backtracking，见 `search-space-backtracking`）。在 6x6 棋盘上，第一行放 0 的话怎么也填不满，所以要回溯好几次，最后在第一行放 1 时找到答案。选择第一个安全的列、从不回头的贪心解法在 5x5 上碰巧正确，但在 4x4 和 6x6 上会失败。

`placed` 是把新皇后添加到前面的，所以下面的行排在最前面。结果必须从最上面一行开始，因此最后反转一次。如果不反转，4x4 会得到 `[2, 0, 3, 1]`，这也是一个正确的摆法，所以顺序问题很难被察觉。如果从大的列开始尝试，找到的就是字典序最大的摆法。
