下面的 `count_solutions(n)` 用回溯统计在 n x n 棋盘上放置 n 个互不攻击的皇后的方法数。它从最上面一行开始，每行放一个皇后，而且只放在安全的列上，逐行往下走。可是 4x4 棋盘的答案得出的是 0，而不是 2。请修复它。

- `is_safe(placed, col)` 是正确的。`placed` 是紧邻上一行的皇后排在最前面的列号列表。
- 填满所有行的一种摆法算作 1。`n` 至少为 1。
- 在不安全的格子上不能再往下搜索。评测会测量 n = 9 以内的搜索开销。

```gleam
count_solutions(4)
// 现在：  0
// 期望值：2
```
