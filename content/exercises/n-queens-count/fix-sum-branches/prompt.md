아래 `count_solutions(n)`은 n x n 체스판에 퀸 n개를 서로 공격하지 않게 놓는 방법의 수를 백트래킹으로 셉니다. 위쪽 행부터 한 행에 하나씩, 안전한 열에만 퀸을 놓으며 내려갑니다. 그런데 4x4 판의 답이 2가 아니라 0으로 나옵니다. 고치세요.

- `is_safe(placed, col)`은 올바르다. `placed`는 바로 윗 행의 퀸이 맨 앞인 열 번호 목록이다.
- 모든 행을 채운 배치 하나를 1로 센다. `n`은 1 이상이다.
- 안전하지 않은 칸에서는 더 내려가지 않아야 한다. 채점에서 n = 9까지의 탐색 비용을 잰다.

```gleam
count_solutions(4)
// 지금:   0
// 기대값: 2
```
