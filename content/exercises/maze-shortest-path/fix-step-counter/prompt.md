아래 `shortest_path`는 미로에서 출발점 `S`부터 도착점 `G`까지의 최소 이동 횟수를 너비 우선 탐색으로 구합니다. 일자 통로에서는 맞는 답이 나오지만, 갈림길이 있는 미로에서는 답이 너무 크게 나옵니다. 고치세요.

- 각 문자열이 한 행이다. `S` 출발, `G` 도착, `#` 벽, `.` 빈칸이다.
- 한 번에 상하좌우 한 칸 움직이며, 벽과 격자 밖으로는 갈 수 없다.
- 최소 이동 횟수를 `Ok`로 돌려주고, `S`나 `G`가 없거나 갈 수 없으면 `Error(Nil)`이다.
- 80x80 격자에서도 빠르게 끝나야 한다.

```gleam
shortest_path(["..", "SG"])
// 지금:   Ok(2)
// 기대값: Ok(1)
```
