下面的 `shortest_path` 用广度优先搜索求迷宫中从起点 `S` 到终点 `G` 的最少移动次数。在笔直的通道里答案正确，但在有岔路的迷宫里答案会偏大。请修复它。

- 每个字符串是一行。`S` 是起点，`G` 是终点，`#` 是墙，`.` 是空格子。
- 每次向上下左右移动一格，不能走进墙或走出网格。
- 用 `Ok` 返回最少移动次数；没有 `S` 或 `G`，或者无法到达时返回 `Error(Nil)`。
- 即使是 80x80 的网格，也必须很快完成。

```gleam
shortest_path(["..", "SG"])
// 现在：  Ok(2)
// 期望值：Ok(1)
```
