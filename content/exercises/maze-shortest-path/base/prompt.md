문자열 목록으로 된 미로에서 출발점 `S`부터 도착점 `G`까지 가는 최소 이동 횟수를 구하세요.

```gleam
pub fn shortest_path(grid: List(String)) -> Result(Int, Nil)
```

- 각 문자열이 한 행이고, 모든 행의 길이는 같다. `S`는 출발, `G`는 도착, `#`은 벽, `.`은 빈칸이다.
- 한 번에 위, 아래, 왼쪽, 오른쪽 이웃 칸으로 한 칸 움직인다. 대각선 이동은 없고, 벽과 격자 밖으로는 갈 수 없다.
- `S`와 `G`는 각각 많아야 한 번 나온다. 둘 중 하나라도 없거나 `G`에 갈 수 없으면 `Error(Nil)`을 돌려준다.
- 칸이 6,400개(80x80)인 격자에서도 빠르게 끝나야 한다.

격자를 `Dict(Pos, String)`으로 바꾸는 `parse_grid`와 문자의 위치를 찾는 `find_cell`은 이미 있습니다. `Pos`는 `#(행, 열)`입니다.

```gleam
shortest_path([
  "S#..",
  ".#.#",
  "...G",
])
// -> Ok(5)   아래, 아래, 오른쪽, 오른쪽, 오른쪽
```
