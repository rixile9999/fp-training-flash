在由字符串列表表示的迷宫中，求从起点 `S` 到终点 `G` 的最少移动次数。

```gleam
pub fn shortest_path(grid: List(String)) -> Result(Int, Nil)
```

- 每个字符串是一行，所有行的长度相同。`S` 是起点，`G` 是终点，`#` 是墙，`.` 是空格子。
- 每次向上、下、左、右的相邻格子移动一格。不能沿对角线移动，也不能走进墙或走出网格。
- `S` 和 `G` 各自最多出现一次。只要缺少其中一个，或者无法到达 `G`，就返回 `Error(Nil)`。
- 即使是有 6,400 个格子（80x80）的网格，也必须很快完成。

把网格转换成 `Dict(Pos, String)` 的 `parse_grid` 和查找字符位置的 `find_cell` 已经提供。`Pos` 是 `#(行, 列)`。

```gleam
shortest_path([
  "S#..",
  ".#.#",
  "...G",
])
// -> Ok(5)   下、下、右、右、右
```
