학기말 우등생 명단을 만드세요. 학생 목록과 인원 `n`을 받아, 점수가 높은 상위 `n`명의 이름을 반환합니다. 단, 경계에서 동점자를 떨어뜨리지 않습니다.

```gleam
pub type Student {
  Student(name: String, score: Int)
}
```

- 학생을 점수 내림차순으로, 점수가 같으면 이름이 `string.compare` 기준으로 앞서는(가나다순) 순서로 늘어놓는다.
- 앞에서 `n`명을 뽑는다. `n`번째 학생과 점수가 같은 학생이 뒤에 더 있으면 그 학생들도 모두 넣는다.
- `n`이 0 이하이면 빈 목록, `n`이 학생 수보다 크면 모든 학생을 반환한다.
- 결과는 늘어놓은 순서대로의 이름 목록이다.

```gleam
honor_roll(
  [Student("다온", 88), Student("가람", 97), Student("나윤", 88), Student("라희", 75)],
  2,
)
// -> ["가람", "나윤", "다온"]
```
