用 `list.take(n)` 截取“前 n 名”很简单，但当第 n 名和下一名同分时，谁能入选就由姓名这种偶然因素决定了。本题的规则是“达到分数线的全部入选”，所以要先求出**分数线**，再按这个分数截取。

1. 从排好序的列表中用 `list.take(sorted, n)` 取前 n 名，再用 `list.last` 取其中最后一名作为分数线。
2. 从排好序的完整列表中，用 `list.take_while` 在分数不低于分数线时一直取。列表已经排好序，所以遇到第一个低于分数线的学生就可以停下。

要点在于，边界情况会借由 `list.take` 和 `list.last` 的性质自动处理。`n` 小于等于 0 时，`take` 给出空列表，`last` 返回 `Error(Nil)`，名单为空。`n` 大于学生人数时，`take` 给出全体学生，分数线就是最后一名，全员入选。可能失败的查询以 `Result` 返回，所以不会漏掉空的情况。

常见错误是把 `list.drop(sorted, n - 1)` 的第一个元素当作分数线。`n` 为 0 时，`drop` 收到 -1，什么也不丢，于是第 1 名成了分数线；`n` 大于学生人数时，找不到分数线，名单变成空的。把排序规则单独抽成 `by_rank_order`，就能原样复用排名表那道题的规则（理论笔记“高阶函数与模块化”）。
