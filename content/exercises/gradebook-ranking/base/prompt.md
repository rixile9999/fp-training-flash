학생 목록을 받아 순위표를 만드세요. 순위표는 `#(순위, 이름)`의 목록입니다.

```gleam
pub type Student {
  Student(name: String, score: Int)
}
```

- 점수가 높은 학생이 앞에 온다.
- 점수가 같으면 이름이 `string.compare` 기준으로 앞서는(가나다순) 학생이 앞에 온다.
- 순위는 정렬된 순서대로 1부터 하나씩 붙인다. 점수가 같아도 순위는 서로 다르다.

```gleam
rank([Student("하준", 90), Student("민서", 97), Student("가은", 90)])
// -> [#(1, "민서"), #(2, "가은"), #(3, "하준")]
```
