교내 경시대회 순위표를 만드세요. 순위표는 `#(순위, 이름)`의 목록입니다. 이번에는 **동점자가 같은 순위**를 받습니다.

```gleam
pub type Student {
  Student(name: String, score: Int)
}
```

- 점수가 높은 학생이 앞에 오고, 점수가 같으면 이름이 `string.compare` 기준으로 앞서는(가나다순) 학생이 앞에 온다.
- 점수가 같은 학생은 같은 순위를 받는다.
- 어떤 학생의 순위는 "자기보다 점수가 높은 학생 수 + 1"이다. 그래서 동점 바로 다음 순위는 동점자 수만큼 건너뛴다(1, 2, 2, 4 방식).

```gleam
rank([
  Student("도윤", 88),
  Student("가은", 95),
  Student("하린", 95),
  Student("나래", 70),
])
// -> [#(1, "가은"), #(1, "하린"), #(3, "도윤"), #(4, "나래")]
```
