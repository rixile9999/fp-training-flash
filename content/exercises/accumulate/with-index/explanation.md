공개 함수 `accumulate_indexed(list, fun)`에는 "지금 몇 번째인가"를 담을 자리가 없습니다. 그래서 위치 번호와 결과 누적자를 인자로 받는 보조 함수 `go`를 두고, 공개 함수는 시작 상태(번호 0, 빈 누적자)만 정해 호출합니다.

```gleam
fn go(items, fun, index, acc) {
  case items {
    [] -> list.reverse(acc)
    [first, ..rest] -> go(rest, fun, index + 1, [fun(first, index), ..acc])
  }
}
```

재귀 한 번이 원소 하나를 처리하므로 `index + 1`이 곧 다음 원소의 위치입니다. 결과를 `acc` 앞에 쌓기 때문에 마지막에 한 번 뒤집어 원래 순서로 되돌립니다. 이렇게 모든 일이 재귀 호출 안에서 끝나는 꼬리 재귀는 호출 스택을 쌓지 않습니다. 필요한 상태를 인자로 들고 다니는 이 방식은 이론 노트 accumulators-and-tail-recursion(누적자와 꼬리 재귀)에서 다룹니다.

흔한 실수는 두 가지입니다.

- 시작 번호를 1로 두는 것: 모든 번호가 한 칸씩 밀립니다. 사람에게 보여 줄 순번이 필요하면 호출하는 쪽에서 `i + 1`을 쓰면 됩니다.
- `list.reverse`를 빠뜨리는 것: 결과가 거꾸로 나옵니다.

입력의 길이와 순서를 보존하므로 이 함수도 「구조를 보존하는 변환, 함자」의 map과 같은 성질을 가집니다. 위치 번호는 변환 함수에 넘기는 추가 정보일 뿐입니다.
