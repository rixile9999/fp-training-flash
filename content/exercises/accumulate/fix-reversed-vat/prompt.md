가격표 모듈에서 `with_vat`가 가격을 거꾸로 된 순서로 돌려준다는 제보가 들어왔습니다. 버그의 원인을 찾아 고치세요.

- `accumulate(items, fun)`: 각 원소에 `fun`을 적용한 새 목록을 반환한다. 순서와 길이는 입력과 같아야 한다. 다른 모듈에서도 쓰는 공용 함수다.
- `with_vat(prices)`: 가격마다 부가세 10%를 더한다. 정수 나눗셈으로 1원 미만은 버린다.
- `list.map`은 쓰지 않는다. 기존 꼬리 재귀 구조를 유지한다.

```gleam
with_vat([1000, 2500, 300])
// 기대: [1100, 2750, 330]
// 현재: [330, 2750, 1100]
```
