有人反馈：价格表模块中的 `with_vat` 返回的价格顺序是颠倒的。请找出错误的原因并修复它。

- `accumulate(items, fun)`：返回对每个元素应用 `fun` 后的新列表。顺序和长度必须与输入相同。这是其他模块也会用到的公共函数。
- `with_vat(prices)`：给每个价格加上 10% 的增值税。用整数除法舍去不足 1 韩元的部分。
- 不使用 `list.map`。保持现有的尾递归结构。

```gleam
with_vat([1000, 2500, 300])
// 期望：[1100, 2750, 330]
// 当前：[330, 2750, 1100]
```
