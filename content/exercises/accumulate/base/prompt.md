목록과 함수를 받아 각 원소에 함수를 적용한 새 목록을 반환하는 `accumulate(list, fun)`을 작성하세요. 표준 라이브러리의 `list.map`이 하는 일을 직접 만드는 문제입니다.

- 결과 목록의 길이는 입력과 같고, 원소 순서도 그대로다.
- 결과 원소의 타입은 입력과 달라도 된다. (`fn(a) -> b`)
- `list.map`, `list.index_map` 같은 map 계열 함수는 쓰지 않는다. 재귀로 구현한다.

```gleam
accumulate([1, 2, 3], fn(x) { x * x })
// -> [1, 4, 9]
```
