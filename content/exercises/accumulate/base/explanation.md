목록은 빈 목록 `[]`이거나 "첫 원소와 나머지 목록" `[first, ..rest]`입니다. 두 경우를 나누면 답이 그대로 나옵니다.

```gleam
case list {
  [] -> []
  [first, ..rest] -> [fun(first), ..accumulate(rest, fun)]
}
```

- 빈 목록을 변환한 결과는 빈 목록입니다.
- 첫 원소를 변환한 값을 맨 앞에 두고, 나머지는 같은 함수로 변환해 뒤에 붙입니다.

입력의 모양(원소 개수와 순서)을 그대로 두고 원소만 바꾸므로, 이것이 이론 노트 「구조를 보존하는 변환, 함자」에서 말하는 map입니다. 재귀가 목록의 구조를 따라 한 칸씩 내려가므로 항상 끝납니다. 이 성질은 이론 노트 structural-recursion-induction(구조적 재귀와 귀납)에서 다룹니다.

흔한 실수는 누적자를 쓰는 꼬리 재귀로 바꾸면서 `[fun(first), ..acc]`로 앞에 쌓고 마지막에 뒤집지 않는 것입니다. 그러면 `[1, 2, 3]`이 `[9, 4, 1]`이 됩니다. 누적자 방식을 쓴다면 끝에서 `list.reverse(acc)`를 한 번 호출해야 합니다. 이 패턴은 이론 노트 accumulators-and-tail-recursion(누적자와 꼬리 재귀)에서 다룹니다.
