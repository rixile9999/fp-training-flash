列表要么是空列表 `[]`，要么是“第一个元素加剩余列表” `[first, ..rest]`。把这两种情况分开，答案就自然出来了。

```gleam
case list {
  [] -> []
  [first, ..rest] -> [fun(first), ..accumulate(rest, fun)]
}
```

- 转换空列表的结果是空列表。
- 把转换后的第一个元素放在最前面，剩余部分用同一个函数转换后接在后面。

它保留输入的形状（元素个数与顺序），只改变元素本身，所以这就是理论笔记“保持结构的变换：函子”中所说的 map。递归沿着列表的结构一格一格往下走，因此一定会结束。这一性质在理论笔记 structural-recursion-induction（结构递归与归纳）中讨论。

常见错误是改写成使用累加器的尾递归时，用 `[fun(first), ..acc]` 往前堆叠，最后却没有反转。这样 `[1, 2, 3]` 会变成 `[9, 4, 1]`。如果采用累加器的方式，必须在最后调用一次 `list.reverse(acc)`。这个模式在理论笔记 accumulators-and-tail-recursion（累加器与尾递归）中讨论。
