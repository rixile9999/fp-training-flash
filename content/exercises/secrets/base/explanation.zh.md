`secret_add(3)` 并不计算数字，而是把**“加 3 这件事”作为值**返回。`fn(x) { x + secret }` 的函数体引用了外层函数的参数 `secret`，匿名函数创建时这个值会被一起捕获（闭包），之后调用时也会用到。所以 `secret_add(3)` 和 `secret_add(10)` 是两个不同的函数。

`secret_combine` 是接收两个函数、生成新函数的高阶函数。`fn(x) { secret_function2(secret_function1(x)) }` 与数学中的组合 g ∘ f 相同。嵌套调用从内向外执行，所以 `secret_function1` 先被应用。

常见错误在于**顺序**。

- 减法和除法不满足交换律，写成 `secret - x`、`secret / x` 就错了。输入 `x` 在左边。
- 如果调换组合顺序，有些情况会碰巧得到相同的值，比如 `secret_combine(secret_multiply(7), secret_divide(3))`，因此发现得晚。请用对顺序敏感的例子来确认，比如 `4 加 3 再除以 7`（= 1）和 `4 除以 7 再加 3`（= 3）。

先把小运算做成值，再按需组合，这正是理论笔记“高阶函数与模块化”的核心。出现新需求时，不用修改已有函数，只要改变组合方式即可。
