把函数列表合成一个，和把数字列表加起来是同一个形状。就像求和的初始值是 0 一样，函数组合的初始值是**什么都不做的函数** `fn(x) { x }`（恒等函数）。用 `secret_combine` 把函数一个个接到它上面，就得到一行 `list.fold(fns, fn(x) { x }, secret_combine)`。空列表时得到恒等函数，也是从初始值自然得来的，不需要另写分支。

`list.fold` 的回调按 `fn(acc, f)` 的顺序接收参数，而 `secret_combine(acc, f)` 会“先应用目前合成好的函数，后应用新函数”。常见错误是把参数反过来写成 `secret_combine(f, acc)`，结果把列表**倒着**应用了。与加法不同，函数组合的顺序很重要。

对于 `secret_repeat`，与其重新写一个递归，不如把它变成“装有 `times` 个同一函数的列表”交给 `secret_combine_all`，这样更稳妥。`list.repeat` 在次数小于等于 0 时返回空列表，所以 0 和负数会自动变成恒等函数。自己写递归时，经常会出现 `times <= 1` 时返回 `f` 这种差一（off-by-one）的基本情形，或者遇到负数时停不下来的递归。

只要有一个小小的组合运算（`secret_combine`）和单位元，就能把整个列表合并起来，这正是理论笔记“高阶函数与模块化”中讨论的模块化的例子。
