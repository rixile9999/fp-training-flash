함수 목록을 하나로 합치는 일은 숫자 목록을 더하는 일과 모양이 같습니다. 합의 초기값이 0인 것처럼, 함수 합성의 초기값은 **아무것도 하지 않는 함수** `fn(x) { x }`(항등 함수)입니다. 여기에 `secret_combine`으로 함수를 하나씩 이어 붙이면 `list.fold(fns, fn(x) { x }, secret_combine)` 한 줄이 됩니다. 빈 목록일 때 항등 함수가 나오는 것도 따로 분기하지 않고 초기값에서 자연스럽게 따라옵니다.

`list.fold`의 콜백은 `fn(acc, f)` 순서로 인자를 받고, `secret_combine(acc, f)`는 "지금까지 합친 함수를 먼저, 새 함수를 나중에" 적용합니다. 흔한 실수는 `secret_combine(f, acc)`로 인자를 뒤집어 목록을 **거꾸로** 적용하는 것입니다. 덧셈과 달리 함수 합성은 순서가 중요합니다.

`secret_repeat`는 새 재귀를 짜기보다 "같은 함수 `times`개의 목록"으로 바꿔 `secret_combine_all`에 맡기는 편이 안전합니다. `list.repeat`는 횟수가 0 이하이면 빈 목록을 돌려주므로 0과 음수가 저절로 항등 함수가 됩니다. 직접 재귀를 쓰면 `times <= 1`에서 `f`를 돌려주는 식의 한 칸 어긋난 기저 사례나, 음수에서 끝나지 않는 재귀가 자주 생깁니다.

작은 조합 연산 하나(`secret_combine`)와 항등원만 있으면 목록 전체를 합칠 수 있다는 점이 이론 노트 "고차 함수와 모듈성"에서 다루는 모듈성의 예입니다.
